# HowToHack - Frontend

React + TypeScript frontend for the HowToHack security scanning platform.

## Requirements

- Node.js 20+
- npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The Vite dev server proxies `/api` requests to `http://localhost:8000`.

## Build

```bash
npm run build
```

## Configuration

Set `VITE_API_URL` environment variable to override the API base URL (default: `/api`).
